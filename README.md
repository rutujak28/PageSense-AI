# PageSense AI

PageSense AI is an AI powered webpage assistant that allows users to chat with any webpage.

## Features

- Ask questions about webpages
- AI powered answers using Gemini
- Webpage summarization
- Key point extraction
- Streamlit interface

## Tech Stack

- Python
- Streamlit
- BeautifulSoup
- Gemini API

## Live Demo
